The Core Challenges

Three pain points that make scheduling in aviation, healthcare & emergency services a true engineering problem.

Dynamic Disruption

Weather, delays, sick leave, equipment failure — plans break in real-time. PDC's customers operate where a feasible schedule at 8 AM is infeasible by 9 AM.

The cost of slow recovery: grounded aircraft, unpaid crew, patient safety risks, lost revenue.

Real-Time

Thousands of Dead Rules

Crew flight-time limits, hospital union contracts, airport slot regulations, ambulance response-time mandates — each industry carries its own constraint labyrinth, and rules change constantly.

The gap: PDC's rule engine captures them, but maintaining & evolving the knowledge base remains manual-heavy.

Complexity

Steep Learning Curve

Dispatchers, operations controllers and roster managers spend years mastering PDC's interfaces. The power is there — but the cognitive load is high.

The missed opportunity: every minute spent navigating UIs is a minute not making strategic decisions.

The AI Agent Solution

Modern LLM agents don't replace Visual Prolog's deep logic — they wrap it with perception, negotiation & natural interaction.

Disruption Recovery Agent

Auto-Detect · Reason · Replan

A monitoring agent connected to PDC's AODB / Ops systems. Detects deviations in real-time, autonomously triggers the constraint solver for optimal recovery, and presents options to the human dispatcher for one-click approval.

Delay Detected Constraint Check Suggest Replan Human Approves
  • Cuts recovery time from ~30 min to ~2 min
  • Respects all regulatory & contract constraints
  • Learns from repeated dispatcher overrides over time
Highest Impact

Demand Prediction Agent

Forecast · Pre-Position · Optimize

An ML-powered agent analyzing historical patterns — flight delays, emergency call volumes, retail footfall — to predict resource demand ahead of time. Feeds anticipatory constraints into the scheduler before disruptions hit.

Historical Data ML Forecast Pre-Optimize Plan Proactive Buffer
  • Shifts from reactive to proactive scheduling
  • Reduces overtime & last-minute scrambling
  • Self-improves as more operational data flows in
Predictive

Multi-Agent Negotiator

Distributed Constraints · Trade-Off

Specialized agents — each representing one stakeholder (crew, fleet, ground ops, maintenance, revenue) — negotiate optimal compromises when conflicting constraints arise. A mediator agent finds the global optimum.

Conflict Event Crew Agent Fleet Agent Ops Agent Optimal Trade-Off
  • Solves distributed constraint optimization at scale
  • Mimics real-world stakeholder negotiation (but faster)
  • Naturally aligns with PDC's multi-domain scheduling
Most Innovative

Conversational Interface Agent

Natural Language · Intent Parse · Act

An LLM-powered layer that lets dispatchers, managers and crew speak (or type) in plain language. Translates intent into structured queries, invokes the Prolog inference engine behind the scenes, and returns human-readable answers.

"Reschedule Jane's shift to Mon" Intent Parse Rule Check "Done. One conflict found..."
  • Dramatically lowers the learning curve for new operators
  • Leverages Dictus's speech tech for voice commands
  • Makes PDC's power accessible to non-expert users
